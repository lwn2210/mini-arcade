# CLASSIC ZONE — Retro Vault: Attribution & Licenses

Multi-platform emulator section. **NES** ships vendored, freely-licensed
homebrew ROMs (16 games). **Genesis** ships 8, **Game Boy** 5, **GBA** 8,
**SNES** 4, **Atari 2600** 3, **ColecoVision** 2, and **Sega Master System** 1
verified freely-licensed homebrew ROMs each.
**PS1/PSP/PS2** ship NO games and NO BIOS — strictly bring-your-own, loaded
client-side. The ColecoVision page hosts homebrew ROMs but requires a
user-provided ColecoVision BIOS (never bundled).

## License evidence

Licenses were verified on 2026-10-15 via the GitHub API
(`https://api.github.com/repos/<repo>` `license.spdx_id`) and by reading each
repo's `LICENSE.txt` from `raw.githubusercontent.com`:

- `pinobatch/240p-test-mini` → SPDX `GPL-2.0`
- `pinobatch/croom-nes` → SPDX `GPL-3.0` (repo `LICENSE.txt` contains the full
  GNU GPL v3 text)
- `pinobatch/allpads-nes` → repo `LICENSE.txt` is the zlib license (not an SPDX
  field on the repo, verified by reading the file directly)
- `pinobatch/thwaite-nes` → SPDX `GPL-3.0`
- `pinobatch/rfk-nes` → SPDX `Zlib`
- `pinobatch/rhde-nes` → SPDX `NOASSERTION`; repo `LICENSE.txt` read directly
  and confirmed a permissive royalty-free redistribution grant by the author
- `pinobatch/zap-ruder` → SPDX `NOASSERTION`; repo `LICENSE.txt` read directly
  and confirmed a permissive royalty-free redistribution grant by the author
- `wendelscardua/stallar` → SPDX `MIT`
- `wendelscardua/file-fixers` → SPDX `MIT`
- `wendelscardua/signos` → SPDX `Unlicense`
- `mike42/8bit-table-tennis` → SPDX `MIT`

The ROMs are the prebuilt release assets published by the author on the official
project GitHub Releases pages, i.e. the author's own distributed binaries.

GBA and Genesis ROM hashes were re-verified on 2026-10-15 by downloading the
official release assets (and, for Flappy Bird GBA, the raw `bin/FlappyBird.gba`
from the repo's default branch) and comparing SHA-256 against the vendored
files — all four match byte-for-byte (hashes in the table above).
`gba/roms/licenses/` additionally carries the upstream license texts for the
15 third-party libraries linked into the GBA ROMs (Butano, libtonc, maxmod,
newlib, AGBabi, gba-link-connection, gbt-player, etc.).

## SNES — 4 games shipped after forensic verification

Two SNES ROMs were initially excluded while provenance was unresolved. A
follow-up forensic verification located the upstream sources, confirmed MIT
licenses, and compared the files byte-for-byte against upstream. Both are now
included in the manifest and catalog; see the ROM table above. Headers at
`0x7FC0` additionally identify the binaries as `BS-DEMO-MPACK` and
`GOTHICVANIA CEMETERY`.
